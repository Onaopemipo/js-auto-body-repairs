# JS Auto Body Repairs Brand System

## Identity

The website uses the supplied JS Auto Body Repairs identity and the
strapline:

> Restore. Protect. Drive with confidence.

## Primary palette

- Performance red: `#E7070B`
- Bright red: `#FF171B`
- Deep red: `#A50303`
- Carbon black: `#09090A`
- Elevated black: `#0F0F11`
- Graphite: `#38383B`
- Gunmetal: `#57575C`
- Metallic silver: `#8A8A8F`
- Light silver: `#D0D0D3`
- Workshop white: `#F5F5F5`

## Usage rules

Red is reserved for primary actions, active states and controlled
highlights.

Black remains the dominant background.

Graphite and silver provide structural separation and secondary detail.

The supplied raster logo has been processed into transparent web assets.
A professionally redrawn SVG should eventually replace the JPEG source.
